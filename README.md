# Cubing Agent

סוכן HTML לבדיקת שיאי ספידקיובינג.

## איך זה עובד

1. המשתמש כותב שאלה חופשית, למשל:
   - `מה שיא העולם ב-3x3 single?`
   - `מה הממוצע העולמי ב-4x4?`
   - `מה שיא ישראל ב-2x2?`
   - `מה שיאי העולם ב-2x2, 3x3, 4x4 ו-5x5 single?`
2. שאלות ברורות מפורשות קודם כל מקומית, כולל בקשות לכמה שיאים יחד. Gemini משמש רק לבקשות דו-משמעיות או מורכבות.
3. התוצאה עצמה נשלפת ממאגר WCA ציבורי המבוסס על WCA Results Export ומתעדכן פעם ביום.
4. הסוכן מאתר גם את המתחרה ואת התחרות שבה הושגה התוצאה, כאשר המידע זמין.
5. ניתן להזין מספר בלתי מוגבל מעשית של מפתחות. בכל שאלה הסוכן עובר על כל המפתחות הזמינים, אבל כל מפתח מנוסה פעם אחת בלבד. לכל ניסיון timeout של 7 שניות, ומפתח שנתקע מקבל cooldown של 5 דקות. כך הסוכן יכול להמשיך למפתח שלישי, רביעי וכן הלאה, בלי להיכנס ללולאה אינסופית.
6. קריאות Gemini משתמשות ב-`streamGenerateContent`. אם מפתח נקטע באמצע, הטקסט שכבר התקבל נשמר ומועבר למפתח הבא, שמקבל הוראה להמשיך את אותה משימה ולהחזיר JSON מלא ותקין במקום להתחיל מאפס.
7. Gemini 3.8 Flash מופעל ב-`thinkingLevel=low`, כי תפקידו כאן הוא parsing קצר ולא פתרון משימה ארוכה.

## הפעלה

פתחו את `index.html` בדפדפן, או פרסמו את המאגר באמצעות GitHub Pages.

אין צורך ב-build או בהתקנת חבילות.

## מפתחות Gemini

את מפתחות ה-API מזינים דרך ממשק ההגדרות באתר. אין מפתחות API בתוך קוד המקור.

ברירת המחדל של המודל היא `gemini-3.8-flash`, וניתן לשנות אותה בשדה ההגדרות.

> אזהרת אבטחה: מכיוון שמדובר באפליקציית HTML שרצה בדפדפן, מפתח ה-API נשלח ישירות מהדפדפן ל-Gemini. אל תכניסו מפתחות סודיים לאתר ציבורי שאינכם שולטים בו. לפרודקשן ציבורי מומלץ להעביר את קריאות Gemini לשרת/Function ולשמור את המפתחות כ-secrets בצד השרת.

## מקור נתוני WCA

היישום משתמש ב-Un­official WCA Public API של Robin Engelbrecht:

https://github.com/robiningelbrecht/wca-rest-api

ה-API מבוסס על WCA Results Export:

https://www.worldcubeassociation.org/export/results

ה-WCA Software Team מפנה ל-API הזה כאפשרות המומלצת לקריאת נתוני WCA דרך API.

## קבצים

- `index.html` – האפליקציה המלאה: UI, סוכן Gemini, מעבר אוטומטי בין מפתחות, קריאת נתוני WCA ופירמוט התשובה.
